## 6. Stand Up Mobile App Foundation (Phase 4)
Parent status: [x] In Progress (foundation complete — ready for Expo build validation)

- [x] Create apps/mobile scaffold with chosen stack.
    - Stack: React Native / Expo SDK 53, Expo Router v4, pnpm workspaces + Turborepo.
    - Navigation: Stack at root (`app/_layout.tsx`) → Welcome screen + `(tabs)/` group (Summary, Pay Breakdown, Accounts).
    - Design tokens (`src/theme/tokens.ts`) mirror desktop CSS variables exactly; `ThemeContext` switches light/dark via `useColorScheme`.
    - Shared UI primitives: `ThemedText`, `ThemedView`, `MetricRow`, `SectionCard`.
    - Metro config (`metro.config.js`) resolves workspace packages via `watchFolders` + `nodeModulesPaths`.
- [x] Integrate core package for read-only plan views first.
    - All budget math uses `calculatePaycheckBreakdown`, `getPaychecksPerYear`, `convertBillToYearly`, `formatCurrency` from `@paycheck-planner/core`.
    - Summary screen: annual net hero card, income flow (gross → deductions → taxes → net), annual spending allocation.
    - Pay Breakdown screen: per-paycheck pre-tax deduction detail, tax line detail, annual totals.
    - Accounts screen: accounts grouped by type with color dots, bills/loans per account.
- [x] Add mobile storage adapter implementation.
    - Document model: `expo-document-picker` + `expo-file-system` opens `.budget` files directly (like Numbers/Excel).
    - `planFileAdapter.ts`: reads plain and AES-encrypted budget files; validates against `BudgetData` shape.
    - `keychainAdapter.ts`: `expo-secure-store` with `requireAuthentication: true` — biometrics (Face ID/fingerprint) gate key retrieval automatically.
    - `recentFilesStore.ts`: AsyncStorage recent-files list (max 10 entries, deduped by URI and planId).
    - `usePlanFile` hook: full orchestration — pick file → detect encryption → try biometric key → prompt for key once → store for future opens.
    - Welcome screen: file picker CTA, recent files list, demo mode, slide-up encryption key entry sheet.
    - Shared assets moved to core: `demoData.ts` (self-contained, no API dependency) and `accountDefaults.ts` (semantic icon keys).
- [x] Add/update tests where necessary.
    - `__tests__/planFileAdapter.test.ts`: decrypt roundtrip, wrong key, invalid JSON, read errors (26 passing assertions total).
    - `__tests__/coreConsumption.test.ts`: generateDemoBudgetData, calculatePaycheckBreakdown, getPaychecksPerYear, formatCurrency, convertBillToYearly.

Phase gate checks:
- [x] mobile app runs independently and can load sample plans using core (demo mode + real .budget files).
